# 0.1.4 扩展补译与验证：KSA 5602 本地预览

检查与实施时间：2026-10-21 至 2026-10-23，北京时间。基于 0.1.3 部件预览继续补译。本报告记录发布前的本地验证状态；0.1.4 经 `developing → PR → main` 流程交付，发布状态以 [v0.1.4 Release](https://github.com/kuxiaowo/KSA-CHINESE/releases/tag/v0.1.4) 为准。未安装到个人游戏目录。

本版已经扩大显示层覆盖，并重新构建、检查及隔离运行。**它仍不能称为全游戏全部文字已精细翻译完成**：更早的更新正文、原生工具库和异常文案、模型与贴图印字，以及全部界面的视觉验收仍有未完成项。

## 对象与边界

仅支持 `2026.10.13.5602`，四项兼容指纹仍与 `compatibility.json` 一致。没有借本轮工作升级游戏，也没有用汉化替换游戏 DLL 或 Core XML。测试使用工作区独立游戏实例及 `work/test-profile-*`，不读取或修改个人存档。

暂停前的 0.1.3 未提交内容已单独快照，继续开发没有重置或覆盖它。0.1.3 的原报告保留，下面的数据以新一轮检查为准。

## 语义和实现上的修正

- 同一个 `EccentricAnomaly` 原标签在两个分支分别输出偏近点角和真近点角。中文按两个经核对的分支显示，不修改角度计算、轨道状态或数值。
- `Moon` 在天体类别处表示“卫星”，月球对象沿用 `Luna → 月球`。固体发动机喷管的 `Expansion` 另用方法作用域显示为“喷管面积比倍率”，不与尾焰瞬态的“膨胀倍率”混用。
- 物质、相态、反应和药柱通过类型化显示读取适配，不回写源数据。物理计算、排序、序列化及真实资源 ID 继续使用原值。
- 新交互标签按规范 ID 处理，中英文使用同一规范标识；未知文本回退原文。辅助字段在最终文字绘制处翻译，不将中文写入输入变量、绑定枚举或资源对象。
- 运行时生成的枚举和静态选项单独适配。零分隔列表保持项数与顺序，数组只生成显示副本；不全局翻译玩家输入缓冲区。
- 实际截图发现“语言”菜单的两个中文字未进入旧字体子集。生成器现同时检查插件源码中的汉字，回归截图已正常显示。另补上控制台风格“版本历史”标题的实际绘制入口。

底稿由本次助手结合源文和所在界面复核，未冒称真人或独立审校。新增大部分显示记录附有当前方法、审计行号或实际枚举证据；数据记录按资源身份定位。自动附加来源位置不等同独立语义复审。

## 交付与保留项

本地包为 `KsaChinese-0.1.4-5602-Portable.zip`，校验值及文件清单见 `portable-package-validation.json` 和对应 `SHA256SUMS-0.1.4.txt`。打包只包含本项目 Mod、字体、许可、启动器及允许分发的加载器；不包含游戏本体、Core 素材、反编译源码、测试驱动或个人档案。
