# 启动预设名称修订

用户指出“星际系统（密集）”不自然。对照 5602 的 SolSystemInterstellar.xml 与 SolSystemDense.xml 后，将两个显示名统一为“太阳系及邻近恒星”和“太阳系及邻近恒星（扩充版）”。

Dense 配置相对普通星际配置新增 2892 个 Asteroid、141 个 Comet、129 个 MinorBody、22 个 LoadFromLibrary 条目，后者包含更多邻近恒星及其成员。两者的 InterstellarGas 参数均为 0.1 atoms/cm³。“扩充版”是根据内容差异采用的说明性译名，避免孤立的“密集”让人猜测密度含义。没有改写系统 ID、轨道参数或游戏模式。

词典、逐条底稿和字体同步更新；字体所需字形无缺失。116 项无图形检查、237 个补丁目标引用仍通过。已替换本机的外部中文词典和字体并保留旧文件备份，现有游戏未关闭，下一次启动读取新词典。尚未取得新版下拉菜单截图。

此修订已进入源码；此前发布的 v0.1.1 ZIP 仍是原始包，本次没有覆盖旧 Release 附件。本机逐文件校验清单已按这次译文修订更新。
