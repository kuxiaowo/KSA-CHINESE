# 0.1.5：5638 适配与补译

检查日期：2026-10-23。用户更新本机游戏后，实际文件版本和官方接口均为 `2026.10.19.5638`。本版按 `developing → PR → main` 流程交付，发布状态见 [v0.1.5](https://github.com/kuxiaowo/KSA-CHINESE/releases/tag/v0.1.5)。原 0.1.0、0.1.1、0.1.2、0.1.4 已按要求全部取消 Pre-release 标记；0.1.3 没有独立发布过。

**正式 Release 是发布状态，不表示全部游戏文字或全部运行场景已完成验收。** 旧 5602 包继续保留；0.1.5 只支持 5638，不放宽未知版本保护。

## 版本差异与实现

新版 KSA.dll SHA-256 为 `98ecbe7d74b0243eede28077ad5e26c135723d854269ad89a3725c488c18c7cb`。依赖、原生 ImGui 与仪表资源指纹见 `assets/KsaChinese/compatibility.json`，共检查 10 项文件身份。

新版 BRUTAL 程序集更名，旧 StarMap 0.4.7 在隔离启动时因找不到 `Brutal.Core.Numerics` 而失败。改用上游明确针对 5638 的 [StarMap 0.4.8](https://github.com/StarMapLoader/StarMap/releases/tag/0.4.8)，核对下载 ZIP SHA-256 与上游记录一致：`5324240f15d6841835158940057359ef011149bbc30b4d50f7b27480df7b2d5c`，并核对其 MIT 许可与随包署名一致。

## 验证与证据

- Launcher、插件、Validation、SmokeDriver 构建通过，无警告、无错误。
- **1049 项无图形检查通过**；712 条补丁目标引用，涉及 567 个不同签名；包括真实安装补丁、原生 ImGui ID、玩家命名、相态与物质不回写、地图调用处适配和独立 ID 保留。
- 4 条新增原生资源接入；实际部件缺失告警的飞船名和部件占位符检查通过，未刻意破坏个人存档触发报错。
- 最终独立回归 `update5638-final` 和单独历史截图 `update5638-history` 均退出码 **0**，stderr 为空。
- 实际注册表在保存/重新加载测试存档前后均检查通过：650 个模板、649 个名称转换，纯型号 `VTR-10` 保留；83 种物质、120 个相态、17 种反应、103 个输入动作均有对应显示翻译。物质身份和原始名称、说明字段未回写。
- 字体包含 1908 个所需码位，缺字为 0；辐射标签、地图和极光设置已有实际图像证据。
- 424 个扩展显示方法身份清单可从本机 AST/IL 与底稿复验。反编译解析仍有语法错误，因此该清单是定位材料；最终结论结合真实指令、补丁安装和运行证据，不将 AST 候选数作为覆盖率。
- 33 文件便携包通过 CRC、重名和全部文件哈希检查；包中插件、词典、字体、显示清单、兼容表和 Mod 清单与实际测试副本一致。未分发游戏 DLL、Core、反编译源、测试驱动或个人档案。
