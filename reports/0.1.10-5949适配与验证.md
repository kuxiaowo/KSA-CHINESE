# KSA Chinese 0.1.10 · Windows 5949 适配与验证

适配 Windows x64 KSA 2026.11.25.5949 与 StarMap 0.5.4。游戏产品提交为 64c3726bd24373931e550030e4ba49c83fb46ed8。对照 5901 核对了兼容清单中的 13 个文件，其中 11 个 SHA-256 发生变化。原文来自实际游戏程序集、Core 资源和随包更新日志。 [Borea 的 5949 版本记录](https://github.com/KSAModding/Borea/pull/1309)

## 改动范围

- 补译存档星系列、已知星系显示名、直接载入与跨星系切换提示，以及星系未安装、多人加入和显存不足重启提示。
- 补译目的地注册表、到访记录、喵航员首次到访界面、计数和状态组合。保留目的地 ID、存档名、星系 ID 和玩家命名。
- 更新生命保障任务计时提示，按游戏原文记录飞越、入轨、着陆及返航的到达条件。
- 新增热防护类别、9 个主部件和 28 个子部件名称，补译编辑器质心显示、拜科努尔 1 号发射台、阴影级联数和部分发动机设计器界面。随包 5949 更新日志的 119 行正文已全部接入。
- 修正 StarMap 重启的工作目录。便携启动器通过进程传递 -load 参数，游戏重启时可以替换旧参数。

感谢 QUNIXNG 在公开提案中记录 AppendFeedSystemBranch<TController> 导致的 Harmony 失败。本轮独立复现了该异常，并在选取补丁目标时排除开放泛型。候选版继续核验 5949 指纹并在初始化失败时整体回退。 [QUNIXNG 的 #17](https://github.com/kuxiaowo/KSA-CHINESE/pull/17)

## 验证

- 代码与资源检查覆盖 388 个启用的原生字符串、占位符、枚举组合、ImGui 标识、英文回退和依赖指纹。实机注册 274 个主部件和 620 个子部件，893 个显示名发生翻译，另一个保留 VTR-10 型号。字体核验 2,045 个码位，缺字数为零。 [词典](translation-validation.json) · [部件审计](parts-5949-audit.json) · [字体](font-validation.json)
- 无图形验证通过 438 项检查和 882 个补丁目标引用，包含真实游戏 IL、5707 至 5901 的继承显示检查、已分发旧版及未知相邻版本拒绝、语言往返和重启参数。 [无头验证](5949-bootstrap-validation.json)
- Windows 5949 实机从地月系统载入真实生成的太阳系测试存档，接管 Rocket 后以退出码 0 结束。截图核对了简中星系列、目的地注册表及到访记录。运行中读取到 8 条喵航员首次到访记录，并打开编辑器的热防护类别。便携包实机用隔离档案里的较高估算触发真实重启，再以同一档案载入太阳系存档，保留了存档名。重启提示在该画面与乘员警报有局部重叠。 [实机记录](5949-runtime-validation.json)
- 在本地构建标准包和便携包，逐项复核 ZIP 清单、SHA-256 与候选插件字节。 [标准包](mod-package-validation.json) · [便携包](portable-package-validation.json)

多人加入、生命保障各类到达条件的完整航行，以及当前测试分辨率之外的排版尚未逐项验证。到访表格沿用游戏原生时间值格式。开放泛型部件提示里的供给系统说明仍可能显示英文。
