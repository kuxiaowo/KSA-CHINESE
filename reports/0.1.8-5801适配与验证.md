# KSA Chinese 0.1.8 · 5801 适配与验证

适配 Windows x64 KSA 2026.11.10.5801（产品提交 a23e92054927a10e6419c16471256f036848d47c）与 StarMap 0.5.4。游戏来自本机更新后的安装，运行使用工作区副本和独立档案。兼容清单固定 KSA.dll 和另外 11 个依赖或显示资源文件的 SHA-256。StarMap ZIP 通过上游资产 SHA-256 校验。安装内的更新日志与镜像逐字节一致。 [5801 更新日志](https://github.com/KSAModding/ksa-versions/blob/264b79011c539f0ea761bd8fead579bc1e74414a/Content/Versions/v2026.11.X.5801.json) · [StarMap 0.5.4](https://github.com/StarMapLoader/StarMap/releases/tag/0.5.4)

## 适配

- 补译生命保障和资源余量、居住区和换座、乘员状态和死因、EVA 取存物资和航天服读数、启动及宇宙规则、警报和储罐提示。
- 接入编辑器的撤销重做、操作提示和部件变体，补译 HDR 界面亮度、场景基准白亮度和自动输出格式。HDR 自动模式按 5801 的实际顺序优先选择 HDR10。
- 逐行处理 242 行 5801 更新正文。修订号、作者和日期继续使用原始元数据，源文件中的单字符残句保留为 y。
- 按 Core 清单顺序核对 Part/SubPart、Modify 和 Parent 对显示名的影响。Key、Ref、KeyRef、枚举和资源标识由游戏解析。插件仅改变显示读取，部件重复编号、玩家名称、数值、单位、占位符和原始字段均由原有游戏逻辑保留。 [部件审计](parts-5801-audit.json) · [5801 部件格式线索](https://github.com/KSAModding/Borea/pull/1197)

## 验证

- 构建和无图形检查通过 313 项，解析并验证 787 个补丁目标引用。检查内容包含实际 IL 常量、格式参数、ImGui ID、兼容性保护和历史正文显示入口。 [构建验证](5801-bootstrap-validation.json)
- 词典中 5,716 条启用审核记录。占位符、格式标记及字形检查通过，Noto SC 子集覆盖 1,993 个所需码位，新增 CO₂ 所用下标 2。 [词典验证](translation-validation.json) · [字体验证](font-validation.json)
- 1920×1080 隔离实机完成中英切换、居住区、名册、显示设置和历史界面抽查。关闭辐射和生命保障后保存，重载恢复了两个关闭状态。编辑器成功切换部件变体并执行撤销重做。另用独立 EVA 档案出舱，经游戏事件队列取出并存回一份餐食。
- 实际注册 258 个主部件和 575 个子部件。832 个部件显示名有中文，VTR-10 保留型号。109 个输入动作有中文标签。运行中对照了 87 种物质、126 个相态、16 个反应，并核对物质的原始字段没有被显示适配修改。 [运行验证](5801-runtime-validation.json)
- 本地构建了标准和便携 ZIP。校验压缩包完整性、文件白名单和 SHA-256。 [标准包](mod-package-validation.json) · [便携包](portable-package-validation.json)

编辑器操作有运行日志。游戏内截图接口未生成编辑器截图。实机覆盖一套飞行分辨率，尚缺所有预警触发、所有舱内转移和换座路径、物理 HDR 输出、长时间运行及 Borea 桌面验收。版本查询在运行中收到 HTTP 502，测试场景完成且进程正常退出。新增简中尚待维护者逐条审阅。
