KSA Chinese 0.1.4 — 5602 简体中文本地预览

仅适配 compatibility.json 中检查过的 KSA 2026.10.13.5602 文件。
通过 StarMap 0.4.7 加载，需要 .NET 10 x64 Runtime。
便携包的启动和卸载说明位于游戏目录下 KsaChinese/README-便携Mod.md；
独立安装方案另见项目 README-安装卸载.md。

“语言 / Language”菜单即时切换 English/简体中文，默认值由 language.json 决定。
原生文本从 JSON native 字典通过提供器接入；zh-CN.resx 是同底稿导出的资源表，
resx 不单独激活显示，主要界面也需要代码补丁。
未审、缺失或上下文冲突的译文回退原文；未知游戏或依赖哈希安全禁用。
本版是部分汉化，覆盖与验证限制见项目报告。
本次扩展 650 个主、子部件显示映射，以及物质、相态、反应、药柱、材料、仪表和高级窗口。
当前 5602 的 135 条更新正文已翻译；更早的更新正文仍可能回退英文。
保留型号/规格代号，纯型号 VTR-10 不改；180 个主部件定义包含隐藏/测试资源，不代表可选部件数。
实际资源键、物理参数和存档不改；贴图印字、原生工具库和全部界面的视觉验收尚未完成。
